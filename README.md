# Budget mensuel

Petit programme en Python, utilisable dans le terminal, pour suivre son budget mois par mois.

## Fonctionnalités

- Noter les entrées d'argent (salaire, job étudiant, aide de la famille, autre)
- Noter les dépenses par catégorie (activité, nourriture, vêtements, makeup/soin, abonnement, autres)
- Mettre de l'argent de côté
- Noter son solde au début et à la fin du mois, avec une vérification que les comptes tombent juste
- Fixer des limites par catégorie, avec une alerte en cas de dépassement
- Voir le bilan du mois et la liste des opérations
- Comparer deux mois
- Changer de mois

## Lancer le programme

Python 3 est nécessaire. Aucune bibliothèque supplémentaire n'est requise.

    python budget_v6.py

## Données

Les opérations sont enregistrées dans `budget.csv` et les limites dans `limites.csv`. Ces fichiers sont créés automatiquement au premier lancement et ne sont pas publiés sur GitHub.

## À propos

Projet personnel pour m'entraîner à programmer en Python (fichiers CSV, fonctions, gestion des dates).
